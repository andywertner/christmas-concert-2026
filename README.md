# Christmas Concert 2026

Three lyric-track pages for the school concert. Each song has its own URL.

Built as plain HTML so it runs on school Chromebooks stuck on Chrome 103. No CSS nesting, `:has()`, `dvh`, `color-mix()`, or container queries. Browser zoom stays on, and each song page has A− / A+ for the lyrics.

Joy to the World and O Come, All Ye Faithful use the concert lyric sheet. Mary, Did You Know? is still under copyright, so that page has the practice track only.
